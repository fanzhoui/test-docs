# 快速开始

本页带你五分钟内跑通 test-docs 文档站。

## 环境要求

- Node.js 18 及以上
- npm 或 pnpm / yarn

## 安装依赖

```bash
npm install
```

## 启动本地开发服务器

```bash
npm run start
```

默认访问地址：`http://localhost:3000`

开发模式下支持热更新，修改 `docs/` 下的文档后会实时刷新。

## 生产构建

```bash
npm run build
```

构建产物输出到 `build/` 目录，可部署到任意静态服务器。
