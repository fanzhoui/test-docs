# 配置说明

test-docs 的站点配置位于根目录的 `docusaurus.config.ts` 文件。

## 站点基础信息

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `title` | 站点标题 | `test-docs` |
| `tagline` | 站点副标题 | `A Docusaurus documentation site` |
| `url` | 站点生产地址 | `https://fanzhoui.github.io/` |
| `baseUrl` | 站点根路径 | `/` |
| `organizationName` | 组织名 | `fanzhoui` |
| `projectName` | 项目名 | `test-docs` |

## 语言设置

```ts
i18n: {
  defaultLocale: 'zh-Hans',
  locales: ['zh-Hans'],
},
```

## 导航栏

导航栏在 `themeConfig.navbar.items` 中定义，常见配置：

- `docSidebar` 类型：链接到文档侧边栏
- `to`：站内链接
- `href`：站外链接

## 侧边栏

侧边栏在 `sidebars.ts` 中配置，默认通过目录自动生成：

```ts
const sidebars: SidebarsConfig = {
  docs: [{type: 'autogenerated', dirName: '.'}],
};
```

## 更多

完整配置项请参考 [Docusaurus 官方文档](https://docusaurus.io/docs/api/docusaurus-config)。
