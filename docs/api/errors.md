# 错误码

test-docs 示例接口返回统一的 JSON 结构，`code` 用于标识结果状态。

## 返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 常见错误码

| code | 含义 | 说明 |
|------|------|------|
| `0`   | 成功 | 请求处理成功 |
| `400` | 参数错误 | 请求参数缺失或格式不正确 |
| `401` | 未认证 | 缺少认证信息或令牌失效 |
| `403` | 无权限 | 当前身份无权访问该资源 |
| `404` | 资源不存在 | 请求的接口或资源不存在 |
| `429` | 请求过于频繁 | 触发了限流策略 |
| `500` | 服务器错误 | 服务内部异常，请联系维护者 |

## 使用建议

- 客户端应优先根据 `code` 而非 HTTP 状态码判断业务结果。
- 联调时如遇 `500`，可开启调试日志定位具体异常。

:::note
以上错误码为示例占位内容，仅用于测试文档站点的展示效果。
:::
