# 认证方式

test-docs 提供的 API 通过令牌（Token）进行认证。

## 获取令牌

登录控制台后，在「个人设置 → 访问令牌」页面可创建 API 访问令牌。请注意：

- 令牌仅创建时完整显示一次，请妥善保存。
- 令牌与账号权限绑定，应遵循最小权限原则。

## 携带令牌

请求时在请求头中携带令牌：

```bash
curl -H "Authorization: Bearer <你的Token>" https://api.test-docs.example.com/v1/docs
```

## 令牌管理

- **有效期**：令牌可设置有效期，到期后需重新创建。
- **撤销**：如令牌泄露或不再需要，可在控制台立即撤销，撤销后即刻失效。
- **轮换**：建议定期轮换令牌，降低泄露风险。

## 常见问题

- **返回 401**：令牌缺失、格式错误或已过期，请检查请求头与令牌状态。
- **返回 403**：当前令牌无访问该资源所需权限，请在控制台检查授权范围。
